新建任务 （从需求条目派生——主路径；本页是 operator 快捷方式，来源需求必填、不可凭空建任务）

本页在派生流中的位置
  • 入口：需求详情页某条目点「派生任务」→ 本页自动锁定来源需求与条目号（只读，防脱节）。
  • 创建 = init-task：task.md 写入 requirement + req_item 引用 → Draft。
  • 下一步：Draft 页上传三件套 → 签署页 H1/H2 → freeze → Ready（条目流水线前进一格）。

owner 自动取当前登录用户（身份锁定）。创建后 task.md 即带需求与条目引用；一个条目可派生多个 task（返场另开），条目进度以「承载任务中走得最远者」显示，Done 后条目关闭。
