任务级协作信箱：session 间异步沟通与人在环决策 draft

task-collab-mailbox · 优先级 P1 · owner：nfsnyy · 条目覆盖 0/5 · 已登记状态仓（8a2b3bb）。
背景：T6 返场一轮中 operator 与执行 agent 的沟通（状态报告 / 决策请求 / 返场指令）全靠人肉在多 session 间搬运文本，沟通过程不入账、审计断截。

目标

围绕同一任务的多个 session（执行/验收/operator）与人，通过平台异步沟通；人只在页面做决策，不再当传话筒。

完成判据（条目 = 派生锚点）

条目判据验证状态
REQ-1agent 经 CLI 向 operator / 另一 actor 发任务级消息（note/question/block），复用提案+sync 写路径，落 events 审计。机测未派生派生任务
REQ-2收件人 sync 后消息投影至工作区 inbox（未读计数），session 启动流程可读。机测未派生派生任务
REQ-3question 类消息在页面形成「待决策」队列；人在页面答复生成 decision 记录与事件，agent 下次 sync 可见。机测 +【人工】未派生 依赖人在环页面能力派生任务
REQ-4页面任务详情可按时间线查看该任务全部协作消息与决策（人面审计视图）。【人工】未派生派生任务
REQ-5T6 式返场流程经信箱流转后，除人在页面点决策外全程无需人工搬运文本。【人工】未派生派生任务
