登录只给身份（无角色）。本页管理你的个人访问令牌（PAT）——agent 无自有账号，PAT 本质是你对某个 session 的授权。

两种凭证的分工（别混用）
  • sigt 任务令牌：在任务详情页「接取/分配」时签发，绑定 task + 你 + 执行者标签，仅对该任务有效——执行任务用。
  • PAT 个人访问令牌：本页签发，绑定你 + scope + 执行者标签——起草需求、发消息等接口动作用。
  • 归因双字段随凭证落账：actor=你（问责）+ on_behalf_of=执行者标签（归属）。
  • confirm / 签署类闸门只认你本人登录——PAT 与 sigt 都不可代过；令牌用毕即吊销，session 关了令牌也别留着。
