防"同源盲区"Against same-source blind spots

起草、实现用同一模型时，用例与代码可能一起窄化条款——异源评审让另一个模型当第四只眼，实证抓到过真缺陷。When drafting and implementation share one model, cases and code can narrow together. A different model reviews as a fourth eye — it has caught real defects in production.

防"验收漂移"Against review drift

交付指纹与入库指纹强制比对；安全面变更另过否决门（冷静期+第二审批）。想悄悄削弱保护？门在那儿。Delivery fingerprints are forcibly compared with ship fingerprints; safety-surface changes pass a veto gate (cooling period + second approver). Want to silently weaken a guard? There's a gate for that.

亮点 ③Highlight ③

凭证体系：授权而不转移问责Credentials: authorize without transferring accountability

PAT

个人 API 令牌Personal API token

agent 替你写需求时的"签名委托书"——按 scope 限定能办的动词，办什么都在你的名义下。A "signed letter of attorney" for agents drafting requirements on your behalf — verbs limited by scope, everything acts in your name.

SIGT

任务委托令牌Task delegation token

"派工单"——一牌一任务，agent 凭它领取任务包、提交交付；任务结束令牌即退役。A "work order" — one token, one task. The agent claims the package and submits delivery with it; the token retires with the task.

agent 没有也不需要独立账号。账本每个事件都记两行：actor（签发人，问责锁定）与 on_behalf_of（执行者，备查）。每一次授权本身都是一条账本事件——"谁把什么权限授给了谁"，页面可查、永远可审。Agents need no accounts of their own. Every ledger event records two identities: actor (the issuer — accountability locked) and on_behalf_of (the executor, for reference). Every grant is itself a ledger event — "who granted what to whom" is one query away, forever.

技术形态Under the hood

简单到可以审计，严肃到可以上堂Simple enough to audit, serious enough to trust

git 即数据库git is the database

状态仓 = 唯一事实源。账本事件流、冻结规格、设计裁定全在 git 里：可克隆、可 diff、可回滚、可审计。零外部依赖，Python 标准库单进程即可跑。The state repo is the single source of truth. Event stream, frozen specs and design rulings live in git: clonable, diffable, rollable-back, auditable. Zero external dependencies — one Python stdlib process.

呈现层零脚本Zero-script presentation

页面与本演示一样：无 JavaScript，纯 CSS 达成双语切换与排版——安全面小、可打印、离线可用、行为可预测。The UI — like this deck — runs no JavaScript: bilingual toggle and layout in pure CSS. Small attack surface, printable, offline, predictable.

单机可跑，向多机演进Runs on one machine, evolving out

今天：本机服务 + 本机 agent。路线已铺：api-remote-ready（CLI 与服务解耦）→ 多 project 注册与样板 → 多用户角色——部署形态升级时安全模型显式声明，不偷偷换。Today: local service, local agents. The path is laid: api-remote-ready (decouple CLI from service) → multi-project registration with starter skeletons → multi-user roles. The trust model is declared with each deployment shape — never swapped silently.

安全是结构，不是口号Security is structure, not slogan

四系凭据×五面授权矩阵机测覆盖；self-review 门防自审自批；安全面变更过否决门（冷静期+第二审批）；令牌哈希落盘、永不外发明文。Four credential families × five surfaces, machine-tested; self-review gates; safety-surface changes pass a veto gate (cooling + second approver); tokens stored hashed, never transmitted in clear.
